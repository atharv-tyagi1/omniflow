# UI DESIGN AUTHORITY

Google Stitch is the primary UI/UX design authority for OmniFlow.

## Workflow

1. Use the uploaded reference image together with Google Stitch (StitchMCP) to design every new page.
2. Google Stitch defines:
   - layout
   - spacing
   - typography
   - visual hierarchy
   - component composition
   - interaction patterns
   - responsive behavior
   - light and dark variants
3. Antigravity is responsible only for implementation.
4. Do not redesign the layout during implementation.
5. Match the approved Stitch design as closely as possible.
6. Use the existing GlassCard, GlassTable, GlassMetricCard, StatusChip, charts, and design tokens to implement the approved design.
7. Maintain a single OmniFlow Design System across all pages.
8. Every future page must first have a Google Stitch design before implementation.
9. Dark mode must match the uploaded reference image.
10. Light mode must be the same layout with equivalent spacing, hierarchy, and premium glass treatment.
